# MIGLICK Studio

Конструктор персональных героев и рамок. Новый интерфейс на основе MiniBrick Studio v7 в стиле лендинга MIGLICK: тёплый фон, фиолетовый акцент, Onest и Unbounded.

## Запуск

Статическое приложение, сборка не нужна. Из этой папки запустите `python3 -m http.server 4174` и откройте http://localhost:4174/ . Для публикации скопируйте содержимое папки на статический хостинг, сохранив структуру assets и fonts.

## Файлы

- index.html — структура интерфейса.
- engine.js — каталоги, составление персонажей, рамки, сохранение, стоимость и экспорт.
- studio.js — навигация по шагам, подсказки и управление модальными окнами.
- studio.css — новый адаптивный интерфейс.
- renderer-legacy.css — сохранённые правила расположения слоёв фигурок и рамки.
- sw.js — сетевой приоритет и отдельный кеш MIGLICK.
- assets/ и fonts/ — изображения и шрифты.

Сохранены исходные цены, контакт ВКонтакте, каталоги, композиция рамки и совместимость с ключами старых черновиков. Черновики хранятся в браузере на устройстве; между разными доменами автоматически не переносятся. Оформление создаёт картинку и текст проекта для передачи в существующий контакт ВКонтакте. Оплата и автоматическая отправка заказа не подключены.

## Проверки

`node --test tests/core.test.cjs`

Девять проверок: повреждённые черновики, пустые данные, сохранение прежних данных, недоступное хранилище, экранирование имён, цены, область кеша и исключение нетронутого черновика из заказа.

Интерфейс проверен в браузере на размерах от 320×700 до 1920×1080. Проверка на физических телефонах ещё не выполнена.
