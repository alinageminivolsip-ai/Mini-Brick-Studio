# MIGLIK — пошаговый конструктор

Рабочая реализация в существующем проекте. Выбранное направление: вариант 1, тёплый белый / графит / бордовый. Главная miglik/ и её scroll-анимации не входят в изменения.

## Запуск и проверки

Из папки constructor: `python3 -m http.server 5194 --bind 127.0.0.1`, открыть http://127.0.0.1:5194/. Для тестов из этой же папки: `node --test tests/*.test.cjs` (27 проверок). Сборка не нужна: статический HTML/CSS/JS. Публикация — копирование runtime-файлов в studio/ существующего GitHub Pages проекта. В index.html / boot.js зависимости имеют версии по содержимому; sw.js обновляет только собственный кэш.

## Новый сценарий

История → Герои → Оформление → Личные детали → Проверка → Корзина → существующее оформление через VK. Настройки независимы от навигации. Desktop: предпросмотр слева, редактор справа. Mobile: закреплённый просмотр рамки и крупного активного героя, горизонтальная полоса героев, категории, контекстное действие внизу. Расширенные палитры и инструменты раскрываются по запросу. GSAP используется для коротких прерываемых переходов, reduced-motion отключает движение.

Корзина: добавить, изменить, скопировать, удалить и отменить удаление в текущей сессии. Незавершённый отдельный черновик паркуется при редактировании сохранённой рамки и восстанавливается после сохранения/отмены. Чёрновик и корзина сохраняются на этом устройстве; это не аккаунт и не облачная синхронизация.

## Архитектура и ассеты

- engine.js: исходная композиция, маски/слои минифигурок, каталоги, расчёт, перенос персонажей, экспорт; точечные исправления.
- renderer-core.css: извлечённые исходные стили слоёв, без конфликтующих прежних интерфейсов.
- guided.js / guided.css: новая логика пяти этапов, визуальные категории, корзина, доступность.
- guided-model.js: ограничения ёмкости и защита существующих черновиков от пресетов.
- media-store.js: текстовое состояние в localStorage, изображения Blob в IndexedDB с SHA-256 ссылками. Фото не передаётся серверу. Старые dataURL мигрируют автоматически; при ошибке прежняя запись не перезаписывается. Удалённые фото не очищаются автоматически из IndexedDB: можно очистить данные сайта в браузере.
- boot.js: последовательный запуск после восстановления фото; loader ждёт критические изображения и локальные шрифты, прочие варианты подгружаются по требованию.
- completion.js/css: существующий итог, экспорт, копирование и контакт VK. Новая палитра.
- fonts/: исходные Onest / Unbounded; vendor/gsap.min.js: локальная GSAP с сохранённой лицензией.
- assets/body/: исходные маски тела; faces/: оригиналы; hair/: волосы; accessories/: реальные предметы и костюмы; prints/: принты; backgrounds/: фоны. Детальная карта: docs/redesign-2026-10-30/FEATURE-ASSET-MAP.md.
- assets/optimized/faces/: девять производных WebP из оригиналов. A7.png фактически PSD; WebP позволяет показать его без изменения оригинала.

Проверены SHA-256 всех 77 исходных файлов: ни один не изменён. Предыдущие shell-файлы сохранены для отката, но не загружаются новым index.html. Полный архив до переработки: ../outputs/MIGLIK-constructor-before-full-redesign-2026-10-30.zip.

## Реально выполненное QA

27 автоматических тестов: стоимость, независимость редактирования и копий, состав заказа, повреждённое/недоступное хранилище, экранирование текста, loader, ёмкость рамок, защита существующих черновиков и приватное хранение фото.

В браузере: два независимо настроенных героя; лицо/волосы/одежда/принт/аксессуар; переходы назад/вперёд; размер и цвет рамки; фон; загрузка реального PNG и подпись; итоговая сумма; сохранение в корзину; копия, изменение только копии, удаление/отмена; обновление с восстановлением двух рамок и фото; сохранение отдельного незавершённого черновика при редактировании корзины. Генерация итоговых изображений заказа из нескольких рамок и переход к выбору способа оплаты/VK. Реальных сообщений и оплат не было. Escape закрывает диалог.

Проверены размеры: 320×700, 360×800, 375×812, 390×844, 430×932, 768×1024, 1024×768, 1280×800, 1440×900. На каждом измерены innerWidth, scrollWidth и положение footer; горизонтального переполнения нет. Сохранены screenshots и responsive.json в qa/redesign-2026-10-30/after/. Для пройденного пути в журнале браузера ошибок не найдено, видимые картинки загружены. Полная матрица всех сочетаний предметов не проходилась.

Аудит до изменений: docs/redesign-2026-10-30/AUDIT.md. Архитектура UX: UX-ARCHITECTURE.md рядом. Визуальное сравнение: design-qa.md. Скриншоты до: qa/redesign-2026-10-30/01..15; после: after/.

## Ограничения

Физический iPhone/Safari, системная клавиатура и VoiceOver не проверялись. Reduced-motion реализован, но переключение системной настройки в этом прогоне не тестировалось. Клавиатурная ловушка реализована; полного аудита WCAG не было. Подготовка изображений подтверждена; факт сохранения PNG в Downloads не подтверждён (событие download не было получено). Оплата и автоматическое размещение заказа отсутствуют в исходном продукте: менеджер завершает оформление через существующий VK. Исследование с реальными покупателями не проводилось.
