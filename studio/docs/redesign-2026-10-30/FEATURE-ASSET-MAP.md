Приложение статическое: HTML, CSS и обычный JavaScript. React и серверной корзины нет. `constructor/` совпадает с опубликованным `studio/` по исходникам приложения; различаются документация и служебные папки.

## Устройство проекта

- `index.html` — оболочка.
- `engine.js` — глобальное состояние, CSS-маски и PNG-слои, miniHTML, DOM-рамка, Canvas-нормализация и экспорт.
- `studio.js` — навигация, подписи, фокус модальных окон.
- `completion.js` — предпросмотр результата, сумма и ручное оформление.
- `loader.js` — предзагрузка64 изображений и четырёх запросов шрифтов, минимальная задержка1.8секунды.
- `sw.js` — отдельный кеш приложения.

## Сохранение данных

Совместимость нужна с ключами `mb_v4_people`, `mb_v4_frame`, `mb_frame_bg`, `mb_frame_bg_scale`, `mb_frame_preset_bg`, `mb_frame_texts`, `mb_cart_v1`, `miglick_editing_item` и остальными параметрами надписей. При переносе изображений новая система должна сначала подтвердить успешное сохранение Blob, затем менять ссылку в конфигурации. IndexedDB остаётся локальной базой, а не шифрованным сервером.
