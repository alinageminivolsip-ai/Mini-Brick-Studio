# Существующий визуальный язык
Белый фон, бордовый #8d283f, тёмный текст #272421. Локальные Unbounded для заголовков и Onest для текста. Реальные авторские фотографии без подмены и деформаций. Просторные редакционные композиции, продукт целиком, выразительная типографика. Режим: Persuade для продуктовых страниц, Read для справочных, Experience для примеров. Существующие сцены и слайдеры сохраняются по прямому требованию владельца.
