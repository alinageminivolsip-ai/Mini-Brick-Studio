# Техническое SEO

HTML существует без JS, заголовки семантические. Шаблон проверяется scripts/check-site.py: один H1, последовательность H1/H2/H3, canonical, локальные ссылки. sitemap.xml не содержит приватные и черновые страницы.

GitHub Pages project site не управляет https://alinageminivolsip-ai.github.io/robots.txt: файл внутри проекта не является origin robots. Поэтому noindex задаётся meta robots на функциональных/черновых страницах. Для robots всего домена нужен отдельный root-сайт аккаунта; не создавался.

Общий og:image сохранён из проекта. Никакие сроки, цены, рейтинги и реквизиты для schema не придуманы. Поисковые инструменты, Search Console и фактическая индексация не проверялись.
