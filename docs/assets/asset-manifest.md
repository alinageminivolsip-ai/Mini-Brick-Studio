Анимационные серии: assets/intro-transparent/intro-v2_*.webp; assets/packaging-sequence-v2/*.webp; editorial/apartment/{small,large}/*.webp (61 кадр). Герои/рамка/коробка и video sources остаются в исходном бандле главной. Новая страница дома использует точную извлечённую реализацию ApartmentPlayer.

Шрифты: fonts/onest-*-wght-normal.woff2 и unbounded-*-wght-normal.woff2, лицензии сохранены. Полный список файлов проекта доступен через git ls-files. Неподключённые старые бандлы не удалены: их отсутствие в HTML не доказывает отсутствие runtime-использования.

Размеры каждого статического изображения записаны в width/height сгенерированного HTML, прочитаны из файла через sips, не заданы общим значением. Видео и покадровые серии остаются с исходными размерами. Правило кадрирования: рамки, упаковка, лица и интерьер полностью сохраняются, используется contain. Вписывание в карточки добавляет свободное поле без растяжения.
