# Реализация

Ветка rebuild/multipage-miglik от fd5b185. Существующий сайт расширен генератором Python без npm-зависимостей. Создано 34 внутренних маршрута + главная; 23 индексируемых URL. Общие компоненты header/footer, хлебные крошки, редакционный hero, карточки, FAQ и CTA.

Главная сохраняет сцены/медиа и добавляет выбор двух направлений; поводы ведут на отдельные страницы. Конструктор и каталог деталей не изменены. Данные корзины/кабинета не мигрировались.

Ограничения: реальный checkout, авторизация, правовые условия и цены не придуманы. Юридические тексты — существующие черновики noindex. Для production требуется завершить проверку и подтвердить бизнес-данные. Публикация не выполнялась.
