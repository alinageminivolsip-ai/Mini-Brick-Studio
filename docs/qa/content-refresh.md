## Оставшиеся ограничения

- Нет аппаратного iPhone, Safari, Firefox, VoiceOver и полного 200% zoom-теста. DOM-проход по 68 состояниям не равен визуальному просмотру всей длины каждой страницы.
- Состав комплектации за 2 490 ₽, сроки, доплаты, доставка, оплата и реквизиты требуют подтверждения владельца. Не придуманы и не заменены публичными TODO.
- Магазин остаётся демонстрационным: реальный checkout/почтовая авторизация не добавлены, заявки и платежи не отправлялись.
- Отзывы сохранены из ранее предоставленного владельцем макета, новые рейтинги или отзывы не создавались. Для дальнейшего продвижения стоит отдельно подтвердить согласия на публикацию материалов.
- Семантическая карта предварительная: целевой регион и поисковые частотности не подтверждены; позиций в поиске никто не обещает.
- robots.txt внутри GitHub Pages project не управляет robots корня домена. Канонические URL, meta robots и sitemap настроены на префикс проекта.
