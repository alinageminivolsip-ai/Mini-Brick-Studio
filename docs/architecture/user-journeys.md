# Пользовательские пути

1. Главная → Рамки → примеры/стоимость → существующий studio.
2. Главная → Миниатюры дома → план/фото/пожелания → подтверждённый канал ВКонтакте.
3. Подарки → событие/получатель → продукт → персонализация.
4. Меню/подвал → Корзина → существующий магазин. Фактическая покупка пока недоступна в демо.

Граница: интерьер не ведёт в редактор минифигурок, а предлагает обсудить проект. Не создаём видимость работающей онлайн-оплаты.
