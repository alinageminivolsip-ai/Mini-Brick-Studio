# Структура

Главная → Рамки / Миниатюры дома → Примеры, идеи подарков, стоимость, как заказать.
Подарки → 6 получателей и 5 поводов.
Подвал → контакты, доставка, FAQ, отзывы, бренд, документы, корзина и кабинет.

Конструктор находится в /Mini-Brick-Studio/studio/. Публичная сборка остаётся статической, без зависимости от серверного fallback.
