# MIGLIK — scroll story

Отдельная демонстрация по приложенному AGENTS_MIGLIK.md. Существующие главная, конструктор, корзина и оформление заказа не изменяются.

## Запуск и сборка

Из этой папки: `npm ci`, затем `npm run dev -- --port 5181`.
Локальный адрес: http://127.0.0.1:5181/.

Сборка для GitHub Pages: `npm run build -- --base=/Mini-Brick-Studio/miglik-scroll-demo/`.
Готовая папка — `dist/`; её содержимое размещается в `miglik-scroll-demo/` основного репозитория Mini-Brick-Studio. Для другого хостинга измените base. Шрифты Onest/Unbounded загружаются из Google Fonts с display=swap; при отказе используются системные, бинарники шрифтов не включены.

## Управление

Обычная прокрутка, восемь кнопок глав, рабочий финальный CTA. GSAP ScrollTrigger из npm, pin и scrub 0.8; единый прогресс 0–100%. Видео не проигрываются по собственному времени. Переходы между несовпадающими ракурсами — непрозрачные редакционные wipes, а не физический 3D-морфинг. Возврат из другой страницы учитывает browser back-forward cache.

`?debug=1` показывает сцену, активный исходник, целевое/фактическое время и начало/конец scroll-диапазона. Выбор процента меняет настоящую позицию страницы. Escape скрывает/показывает диагностику. `?static=1` или `?motion=reduce` включает ту же читаемую статичную ветку, что prefers-reduced-motion. Начальное изображение есть в HTML до загрузки GSAP.

## Ограничения

Физический iPhone, Safari/WebKit, адресная строка iOS, настоящее touch-поведение и throttled-network не проверены. Эмуляция размера не доказывает плавность на реальном устройстве. Режим reduced motion проверен параметром URL, системная настройка ОС не переключалась. Декодированные последовательности занимают память; второй набор загружается ближе к упаковке. Скорость кадров на старых iPhone требует проверки на устройстве.

Клипы 910×512 имеют другой ракурс/пропорции относительно вертикальных JPEG: они показаны без растягивания. Переходы — монтажные, без выдуманного вращения, полёта фигурок и руки с биркой. На самой границе следующая глава начинает wipe с предыдущего изображения. Это демонстрация, не обещание автоматической генерации фигурок из фотографий. Реальный заказ не отправлялся, оплата не выполнялась.

После публичной проверки добавлено сохранение scroll-прогресса при позднем пересчёте шрифтов/метаданных видео; 72 точки повторно проверены на финальном коде. На публичной странице проверены загрузка GSAP, финал и переход в действующий конструктор. При возврате браузер без back-forward cache загружает историю с начала. Ключевые скриншоты сняты до последней правки жизненного цикла; композиция и ассеты не менялись.
