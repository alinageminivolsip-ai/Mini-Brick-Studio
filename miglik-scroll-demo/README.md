# MIGLIK — новая scroll-история

Основной публичный адрес: https://alinageminivolsip-ai.github.io/Mini-Brick-Studio/miglik/ . Дополнительный адрес: https://alinageminivolsip-ai.github.io/Mini-Brick-Studio/miglik-scroll-demo/ . Конструктор остаётся /studio/. Прежняя главная сохранена по /miglik/previous.html с исходными файлами.

## Текущая последовательность

1. 0–28%: новое видео с фотографией `kling_20261029_VIDEO_Premium_ci_5637_0.mp4` → `public/assets/intro-v2.mp4`.
2. 28–48%: предоставленная прозрачная рамка `Изображение ChatGPT 29 окт. 2026 г.png` → `frame-alpha.png`. Отдельного экрана с фотографией людей и старой пустой рамки больше нет.
3. 48–72%: эта же рамка уменьшается и опускается в `коробка.png` → `open-box-alpha.png`. Оба PNG скопированы побайтово, альфа-канал сохранён.
4. 72–96%: `kling_20261029_VIDEO_Ultra_phot_5586_0.mp4` → `packaging-v2.mp4`: коробка, формирование банта, бирка.
5. 96–100%: последний извлечённый кадр того же нового ролика и рабочая ссылка в действующий конструктор MIGLICK.

Нумерация файлов в сообщении трактовалась по их фактическому содержимому: Premium — фотография; Ultra — упаковка. Оба оригинальных MP4 сохранены без перекодирования. SHA-256 новых файлов: [qa/new-media-provenance.json](qa/new-media-provenance.json). Исторические исходники оставлены в assets для архива, текущая страница их не запрашивает.

## Анимация

GSAP ScrollTrigger, pin, scrub 0.8, нормальная прокрутка в обе стороны. В мобильном режиме используется по 31 WebP-кадру 512×640, извлечённому из новых роликов; четыре параллельных декодирования, ближайший готовый кадр и статичный постер при загрузке. Desktop использует currentTime при остановленном видео. MP4 со звуком не запускаются самостоятельно.

Движение рамки — 2D-проективная композиция по реальным углам PNG и проёма коробки. Центральная область уже вложенной рамки в изображении коробки временно маскируется, чтобы не показывать вторую пару фигурок. После совпадения используется исходный полный PNG коробки. Это художественная композиция двух ракурсов, не свободное 3D-вращение. Изображения и alpha не перерисованы.

Между разными сценами — непрозрачные wipes без наложения людей друг на друга. Начальный постер находится прямо в HTML. При уменьшенном движении отображаются пять статичных глав, в упаковке — целая коробка.

## Запуск и сборка

Для **основной** страницы: `npm run build -- --base=/Mini-Brick-Studio/miglik/ --outDir dist-main`. Размещать содержимое dist-main/ в miglik/, сохраняя previous.html и старые assets. Сборка ниже относится к дополнительной странице.

Из этой папки: `npm ci`, `npm run dev -- --port 5181`. Локальный адрес: http://127.0.0.1:5181/ .

Сборка GitHub Pages: `npm run build -- --base=/Mini-Brick-Studio/miglik-scroll-demo/`. Опубликовать содержимое dist/ в miglik-scroll-demo/ репозитория Mini-Brick-Studio. Для другого пути изменить base. Google Fonts Onest/Unbounded с display=swap, системные fallback; бинарники шрифтов не добавлены.

`?debug=1` — сцена, процент, исходник, время видео и выбор позиции; Escape скрывает/показывает панель. `?motion=reduce` или `?static=1` — читаемая статичная ветка, та же ветка включается по prefers-reduced-motion.

## QA новой версии

Встроенный браузер Codex, локальная сборка. 144 состояния: 18 точек в обе стороны на реальных viewport **1440×900, 1280×800, 390×844, 320×700**, включая 52/56/60/64/68% внутри укладки рамки. Геометрия записана через innerWidth/innerHeight, текущий прогресс совпадает с выбранным, горизонтального переполнения, повреждённых активных изображений и выходящего за экран текста не найдено. Отдельная фотография людей отсутствует в DOM. Видео paused. [Измерения](qa/media-v2/checks.json), [console errors](qa/media-v2/console.json).

Скриншоты текущей версии находятся в qa/media-v2/: desktop-* и mobile-* для intro, frame, placement-start, placement-middle, placement-aligned, box, ribbon, final; [контактный лист](qa/media-v2/contact.jpg). Они сняты с фактическими размерами 1440×900 и 390×844. Статичная ветка проверена через URL на 390×844: пять глав, финальная кнопка видна, нет горизонтального переполнения. Сборка Vite и проверка синтаксиса JS успешны.

Ранее созданные qa/current и файлы прямо в qa/ относятся к предыдущему монтажу и не подтверждают нынешнюю версию. Новые PNG имеют размеры 1122×1402 и реальный alpha 0–255. Производные постеры и кадры извлечены из предоставленных роликов через AVFoundation, исходные изображения не редактировались.

## Практические ограничения

Физический iPhone, Safari/WebKit, клавиатура/адресная строка iOS и искусственно замедленная сеть не проверены. Эмуляция размера не доказывает частоту кадров на устройстве. Белый фон внутри самих видео сохранён: видео не имеют alpha; прозрачность сохранена у двух PNG. Переход от открытой коробки к ролику закрытой коробки монтажный, без выдуманной анимации крышки. Реальная оплата и отправка заказа не выполнялись.
